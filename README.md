# PixelZone Games - Sitio Web HTML5

¡Bienvenido al repositorio del proyecto **PixelZone Games**! Este sitio web corresponde a la entrega de la **Semana 1** de la asignatura Desarrollo Frontend.

---

## 📌 Descripción del Proyecto
PixelZone Games es una tienda en línea enfocada en la venta de videojuegos, consolas de última generación y accesorios gamer. El proyecto consiste en una estructura web estática multinivel desarrollada bajo estándares de **HTML5 Semántico** y validada mediante **W3C**.

---

## 📂 Estructura del Sitio Web
El proyecto está compuesto por los siguientes archivos:

* **`index.html`**: Página principal del sitio que incluye el encabezado, menú de navegación principal, sección de productos destacados (con imágenes y descripciones breves) y pie de página institucional.
* **`productos.html`**: Catálogo general que despliega las categorías de consolas, videojuegos y accesorios.
* **`contacto.html`**: Sección con los canales de atención, correo electrónico, teléfono y horarios.

---

## 🛠️ Tecnologías y Estándares
* **HTML5 Semántico:** Uso de etiquetas `<header>`, `<nav>`, `<section>`, `<article>`, `<footer>` para estructurar el contenido.
* **Accesibilidad Web:** Incorporación de atributos `alt` descriptivos en todas las imágenes.
* **Validación W3C:** Código verificado y libre de errores de sintaxis en el *W3C Markup Validation Service*.
